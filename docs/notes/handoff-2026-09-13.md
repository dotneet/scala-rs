This batch removed large reader/compiler clusters:

- macro tree transport now preserves match/case/bind/unapply/star/wildcard
  trees, explicit/implicit argument clauses, repeated arguments, and source
  symbol ownership; `_root_` qualification prevents local package-name capture
- adjacent bare blocks no longer parse as accidental function application
- path-dependent nullary `apply` selection preserves the receiver prefix
- Scala object-only static-forwarder classes are pickle carriers only; module
  runtime identity remains `Foo$` (the prior form caused `NoSuchFieldError`)
- Cats `Parallel.Aux` refinements now pickle their fresh parameter with
  `PARAM | DEFERRED` instead of the invalid `FINAL` flag
- source `List` is pickled through `scala.package.List`, so a real scalac
  reader can find `Foldable[List]`; false higher-kinded erasure bridges are no
  longer emitted, and private value-class constructors carry nsc's boxing flag
- module singletons pickle as `SINGLEtpe`, source `scala.Seq` aliases through
  `scala.package.Seq`, and stale origin-less classpath terms are removed when a
  pickled accessor method replaces them
- inherited external implicit conversions are loaded for requested extension
  members, restoring ScalaTest `when` / `should` / `in`
- refined/intersection JVM signatures choose the non-trait class dominator
  (`Query with TableQuery` now erases to `TableQuery`)
- a narrow duplicate-overload collapse handles a compatible pickled method and
  origin-less classpath declaration without merging unrelated overloads
- JVM method `Signature` attributes and nested pickle `METHODtpe` clause sizes
  now survive classpath loading, restoring generic TableQuery accessors and
  curried `processTree(git, id)(f)`
- Java generic stubs are completed before implicit-view/member lookup and Java
  names inside pickled method types are reconciled with JVM descriptors; this
  restores Twirl's Java collection view and its `List.last`
- nested case companions carry the module-class-rooted pickle, so named
  arguments use the companion `apply` parameter symbols
- trait-local lifted helpers no longer collide after erasure, while
  `protected[this]` trait methods remain inheritable; primitive-return bridges
  use their real JVM return opcode
- inherited overloads are no longer advertised as child-owned erasure bridges,
  eliminating Cats' nonexistent `Traverse.compose$` / `Alternative.compose$`
  calls
- macro wire reconstruction preserves an empty first argument clause before a
  filled implicit clause, and externally supplied Scala runtime symbols are not
  misclassified as this compile run's source symbols
- Java exception parents are completed before typed-pattern compatibility, and
  ScalaSignature-derived `AnyVal` parents survive JVM class metadata loading;
  these fixes restore Slick's `AbstractMethodError` catches and fs2 value-class
  extension calls
- descriptor-created Scala class placeholders are re-homed and renamed when
  the authoritative classfile arrives, so an encoded nested operator such as
  `Outer$$plus$plus` remains `Outer#++` instead of becoming a false nesting
  chain
- static nested objects such as `ExecutionContext.Implicits` are no longer
  given an enclosing-instance constructor argument, and nested binary
  class/module pairs can both complete without reopening package-level module
  signatures
- a binary trait's `lazy val` remains recognizable after on-demand pickle
  completion changes its eager `Term` representation into an `ACCESSOR`
  method; implementing classes therefore emit the cache field, bitmap, and
  accessor instead of silently recomputing the trait default
