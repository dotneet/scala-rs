## Prototype result

The existing drop_classfile_forwarders rule compares the installation owner
(Seq) with AbstractIterable and misses their shared original declaration
(Iterable). faithful_bytecode_copy also treats singleton loss as a different
signature even though the JVM cannot retain this.type.

The local prototype resolves the original owner from pickled_origin and
compares the signature after widening the installing owner's ThisType to the
original declaration's raw class. This removed the lossy AbstractIterable
candidate in the trace. Full-cats diagnostic compilation now has 159 errors
versus the accepted baseline's 163; no error-message additions. Exactly the
four BuildFrom[Iterable,...] messages disappeared (two B, two Ior[A,B]).
Evidence: /tmp/lazyzip-origin/selection-before.log and selection.log.

This is not gated or accepted. The next requirements are an executable small
regression that fails on the accepted binary, bidirectional scalac probes,
and the mandatory pickle/prelude boundary suites. Temporary selection tracing
is still present and must be removed before committing the final fix.

## Executable regression

`tests/fixtures/lzorigin.scala` is a small ArraySeq example: the ArraySeq
member lookup and an earlier Seq.lazyZip populate the two inheritance paths,
then a generic ArraySeq lazyZip/map requires BuildFrom. The accepted binary
rejects it with the same BuildFrom[Iterable,B,C] diagnostic as cats (saved in
/tmp/lazyzip-origin/repro-before.log). The prototype and scalac both execute
with java -Xverify:all and produce byte-identical `5\n` output.
The explicit unsafeWrapArray construction avoids an unrelated ArraySeq.apply
inference issue. LazyList-only versions did not load the same parent graph;
they are not the regression test.

The negative fixture assigns an Int-producing map to ArraySeq[String]. Both
compilers reject it: scalac reports inability to construct the requested
collection, while scala-rs reports a type mismatch. The temporary selection
traces have been removed from compiler source. The lzorigin Rust integration
test performs these acceptance/rejection and execution comparisons.

Boundary verification: /tmp/lazyzip-origin/boundary.log records 535 passed,
zero failed across lzorigin, overloadshadow, ambigmap, setapply, uniteq,
integral, ordsummon, mutcoll, conform and e2e. Full merge gate remains pending.
